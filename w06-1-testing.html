01

Heading — H1 ถึง H6

แท็กหัวข้อมี 6 ระดับ ใช้จัดลำดับความสำคัญของเนื้อหาในหน้าเว็บ ยิ่งเลขน้อยยิ่งสำคัญมาก ตัวอักษรจะใหญ่ที่สุดที่ H1 และเล็กลงเรื่อยๆ จนถึง H6

  • <h1> หัวข้อใหญ่สุด — ใช้ครั้งเดียวต่อหน้า เป็นชื่อหลักของเว็บ/บทความ
  • <h2> หัวข้อรอง — แบ่ง section ใหญ่ของเนื้อหา
  • <h3> หัวข้อย่อยของ h2 — ลงรายละเอียดต่อ
  • <h4> ย่อยลงไปอีกระดับจาก h3
  • <h5> ใช้น้อย เน้นลำดับข้อมูลเฉพาะจุด
  • <h6> เล็กที่สุด ใช้กับหัวข้อระดับลึกมาก
<h1>ใหญ่สุด
ชื่อหลักของหน้า ควรมีแค่ 1 อันต่อหน้า ช่วยเรื่อง SEO
H1: หัวข้อหลัก
<h2>หัวข้อรอง
แบ่งเนื้อหาเป็นหมวดใหญ่ๆ ในหน้าเดียวกัน
H2: หัวข้อรอง
<h3>หัวข้อย่อย
ซอยเนื้อหาใน h2 ให้ละเอียดขึ้น
H3: หัวข้อย่อย
<h4>ระดับ 4
ย่อยลงไปอีกขั้นจาก h3
H4: ระดับที่สี่
<h5>ระดับ 5
ใช้ไม่บ่อย เน้นจัดลำดับข้อมูลย่อยมาก
H5: ระดับที่ห้า
<h6>เล็กสุด
หัวข้อระดับลึกสุด ตัวเล็กสุด
H6: ระดับที่หก
โค้ดตัวอย่าง
<!-- โครงสร้าง heading มาตรฐาน --> <h1>Welcome to My Website</h1> <h2>HTML Basics</h2> <h3>What is HTML?</h3> <h4>HTML Syntax</h4> <h5>Example Code</h5> <h6>Note: Case Sensitive</h6>
💡 กฎที่ชอบออกสอบ
1. ใช้ H1 เพียงอันเดียว ต่อหน้าเสมอ (ช่วยเรื่อง SEO และโครงสร้างเอกสาร)
2. ห้ามใช้ heading เพื่อทำตัวอักษรให้ใหญ่/หนา เฉยๆ — heading มีไว้บอกโครงสร้างเนื้อหา ถ้าอยากได้แค่ตัวหนา/ใหญ่ ให้ใช้ CSS แทน
3. เรียงลำดับจากมากไปน้อย ไม่ควรข้ามระดับมั่วๆ (เช่น จาก h2 กระโดดไป h5 เลย)
02

Text Formatting

แท็กจัดรูปแบบข้อความ ใช้เน้นคำ/วลีให้มีความหมายพิเศษ เช่น สำคัญ เน้นเสียง ขีดเส้นใต้ ฯลฯ มีทั้งกลุ่มที่ "มีความหมายเชิงความสำคัญ" (semantic) และกลุ่มที่ "ปรับรูปลักษณ์อย่างเดียว" (presentational)

<b>Bold
ตัวหนา ไม่มีความหมายพิเศษ แค่ปรับรูปลักษณ์
ข้อความตัวหนา
<strong>Strong
ตัวหนา + สื่อว่า "สำคัญมาก" (semantic) เครื่องอ่านหน้าจอจะเน้นเสียง
ข้อความสำคัญ
<i>Italic
ตัวเอียง ไม่มีความหมายพิเศษ มักใช้กับศัพท์เทคนิค/ชื่อเฉพาะ
ข้อความตัวเอียง
<em>Emphasis
ตัวเอียง + สื่อว่า "เน้นเสียง/อารมณ์" (semantic)
ข้อความเน้นเสียง
<u>Underline
ขีดเส้นใต้ (ระวังสับสนกับลิงก์ ควรใช้ให้เหมาะสม)
ข้อความขีดเส้นใต้
<mark>Highlight
ไฮไลต์พื้นหลังสีเหลือง เน้นข้อความให้โดดเด่น
ข้อความที่ถูกเน้น
<small>Small
ตัวอักษรขนาดเล็กลง มักใช้กับ disclaimer/ลิขสิทธิ์
ข้อความขนาดเล็ก
<del>Delete
ขีดฆ่ากลางข้อความ สื่อว่า "ถูกลบ/ไม่ใช้แล้ว"
ข้อความที่ถูกลบ
<sup>Superscript
ตัวยก (เลขยกกำลัง, เชิงอรรถ)
x2
<sub>Subscript
ตัวห้อย (สูตรเคมี เช่น น้ำ)
H2O
โค้ดตัวอย่าง
<b>ข้อความตัวหนา</b> <strong>ข้อความสำคัญ</strong> <i>ข้อความตัวเอียง</i> <em>ข้อความเน้นเสียง</em> <u>ข้อความขีดเส้นใต้</u> <mark>ข้อความที่ถูกเน้น</mark> <small>ข้อความขนาดเล็ก</small> <del>ข้อความที่ถูกลบ</del> x<sup>2</sup> H<sub>2</sub>O

<b> vs <strong>

หน้าตาเหมือนกัน (ตัวหนาทั้งคู่) แต่ <b> ไม่มีความหมายพิเศษ ส่วน <strong> สื่อว่าเนื้อหาส่วนนี้ "สำคัญ" จริงๆ — โปรแกรมอ่านหน้าจอ (screen reader) จะเน้นเสียงต่างกัน

<i> vs <em>

หน้าตาเหมือนกัน (ตัวเอียงทั้งคู่) แต่ <i> ใช้กับศัพท์เทคนิค/ชื่อเรื่อง ส่วน <em> สื่อว่า "เน้นน้ำเสียง" ตอนอ่านออกเสียง

💡 กฎที่ชอบออกสอบ
แท็กที่ "หน้าตาเหมือนกันแต่ความหมายต่างกัน" คือคู่ที่ชอบออกข้อสอบเปรียบเทียบ: b/strong และ i/em จำหลักไว้ว่า ตัวที่มีความหมาย (semantic) = strong, em, del, mark ส่วนตัวที่ปรับรูปลักษณ์อย่างเดียว = b, i, u, small
03

Link — แท็ก <a>

แท็กสร้างลิงก์เชื่อมไปหน้าอื่น เว็บอื่น หรือตำแหน่งอื่นในหน้าเดียวกัน ใช้ attribute href เป็นหลัก

  • href ปลายทางที่จะลิงก์ไป (URL หรือชื่อไฟล์)
  • target="_blank" เปิดลิงก์ในแท็บ/หน้าต่างใหม่
  • title ข้อความ tooltip ที่ขึ้นตอนเมาส์ชี้ค้าง
  • #id ลิงก์ไปยังตำแหน่งภายในหน้าเดียวกัน (anchor link)
โค้ดตัวอย่าง
<!-- ลิงก์ไปหน้าอื่นในเว็บเดียวกัน --> <a href="index.html">กลับหน้าแรก</a> <!-- ลิงก์ไปเว็บภายนอก เปิดแท็บใหม่ --> <a href="https://www.google.com" target="_blank">ไปที่ Google</a> <!-- ลิงก์ไปยังตำแหน่งในหน้าเดียวกัน (anchor) --> <a href="#section2">ไปหัวข้อที่ 2</a> <!-- ทำให้รูปภาพกลายเป็นลิงก์ --> <a href="about.html"> <img src="profile.jpg" alt="รูปโปรไฟล์"> </a>
💡 กฎที่ชอบออกสอบ
1. ลิงก์ภายในเว็บเดียวกัน ใช้ path แบบสัมพัทธ์ เช่น href="about.html"
2. ลิงก์ไปเว็บอื่น ต้องใส่ https:// เต็มรูปแบบเสมอ
3. target="_blank" ไม่ใส่ = เปิดหน้าเดิมทับ, ใส่ = เปิดแท็บใหม่
03

Image — แท็ก <img>

แท็กแทรกรูปภาพ เป็น empty element (ไม่มีแท็กปิด) ต้องมี attribute src และ alt เสมอ

  • src ที่อยู่ของไฟล์รูปภาพ (path หรือ URL)
  • alt คำอธิบายรูป แสดงเมื่อโหลดรูปไม่ได้ และช่วย SEO/คนตาบอด
  • width / height กำหนดขนาดรูปภาพ (หน่วย px)
  • title tooltip ตอนเมาส์ชี้ค้างที่รูป
โค้ดตัวอย่าง
<!-- แทรกรูปภาพพื้นฐาน --> <img src="img/rabbit.jpg" alt="กระต่าย"> <!-- กำหนดขนาดรูป --> <img src="img/rabbit.jpg" alt="กระต่าย" width="200" height="200">

object-fit: cover

ตัดรูปให้เต็มกรอบ โดยรักษาสัดส่วน อาจถูกครอปขอบบางส่วน (ใช้บ่อยสุด)

object-fit: contain

ย่อรูปให้พอดีกรอบทั้งหมดโดยไม่ครอป อาจเหลือพื้นที่ว่างด้านข้าง

💡 กฎที่ชอบออกสอบ
1. <img> เป็น self-closing tag ไม่มี </img>
2. alt ห้ามลืมใส่เด็ดขาด แม้รูปจะโหลดได้ปกติ เพราะเป็น accessibility ที่สำคัญมาก
3. การกำหนดขนาดรูปควรใช้ CSS (width, height ใน CSS) มากกว่าใส่ attribute ตรงๆ ในบางกรณี เพื่อความยืดหยุ่น responsive
04

CSS ตกแต่ง — กรอบ, มุมโค้ง, เงา, อิโมจิ

พวก card สวยๆ กรอบเส้นประ กล่อง tip-box ที่เห็นในตัวอย่าง Workshop ทำจาก CSS ไม่กี่ตัวผสมกัน จำหลักการเหล่านี้ไว้ เอาไปประกอบเป็นการ์ดสวยๆ ได้เอง

borderเส้นขอบ
รูปแบบ: border: ความหนา ชนิดเส้น สี;
border: 2px solid
border (dashed)เส้นประ
เปลี่ยน solid → dashed ได้กรอบเส้นประแบบ tip-box
border: 2px dashed
border-radiusมุมโค้ง
ยิ่งค่าเยอะยิ่งโค้งมน ใส่ 999px หรือ 50% = กลมเต็มวง
border-radius: 16px
box-shadowเงา
รูปแบบ: box-shadow: x y blur สี;
box-shadow: 0 6px 14px
gradientไล่สี
รูปแบบ: background: linear-gradient(องศา, สี1, สี2);
gradient พื้นหลัง
emojiไอคอน
พิมพ์อิโมจิตรงๆ ใน HTML ได้เลย ไม่ต้องใช้ไฟล์รูป ปรับขนาดด้วย font-size
💡 🎓 ⚡ 🔧 ✅
โค้ดตัวอย่าง — การ์ดไอคอนวงกลม (แบบใน card-header-icon)
/* วงกลมไล่สี ใส่อิโมจิตรงกลาง */ .icon-circle { background: linear-gradient(135deg, #B896FF, #7FCFE8); width: 38px; height: 38px; border-radius: 50%; /* ทำให้เป็นวงกลม */ display: flex; justify-content: center; align-items: center; font-size: 18px; }
โค้ดตัวอย่าง — กล่อง tip-box กรอบเส้นประ
.tip-box { border: 2px dashed #E3B8F5; background-color: #fff; border-radius: 24px; padding: 20px; box-shadow: 0 6px 18px rgba(184,150,255,.18); }
🔧
ตัวอย่างผลลัพธ์: กล่องนี้ประกอบจาก border-dashed + border-radius + box-shadow + อิโมจิในวงกลมไล่สี ผสมกันแค่ 4 อย่างนี้ก็ได้การ์ดสวยๆ แล้ว

🔍 ใส่ค่าไหน ได้ผลยังไง — เทียบให้ดูชัดๆ

ปรับตัวเลขใน property เดียวกัน แล้วดูว่ารูปร่างเปลี่ยนไปแค่ไหน จำง่ายกว่าท่องเฉยๆ

border-width — เส้นขอบหนาขึ้นเรื่อยๆ
1px solid
เส้นบางมาก
3px solid
ขนาดที่ใช้บ่อยสุด
6px solid
เริ่มเห็นชัด กินพื้นที่กล่อง
14px solid
หนาเกินไป กล่องข้างในเล็กลงชัดเจน
border-radius — จากเหลี่ยมกลายเป็นวงกลม
0
เหลี่ยมคม ไม่โค้งเลย
8px
โค้งมนนิดหน่อย แบบการ์ดทั่วไป
20px
โค้งชัดเจน แบบปุ่ม/tip-box
50%
กลมเต็มวง (ต้อง width=height เท่ากัน)
box-shadow — ระยะ blur มากขึ้น เงายิ่งฟุ้ง
0 2px 0
blur=0 เงาคมเป็นเส้นตรง
0 4px 8px
เงานุ่มขึ้นเล็กน้อย
0 8px 20px
เงาฟุ้งกว้าง แบบการ์ด hover
0 16px 34px
เงาลึกมาก เหมือนกล่องลอยสูง
linear-gradient — เปลี่ยนองศา ทิศทางสีก็เปลี่ยน
0deg
ไล่สีจากล่างขึ้นบน
90deg
ไล่สีจากซ้ายไปขวา
135deg
ไล่สีทแยงมุม (ใช้บ่อยสุด)
180deg
ไล่สีจากบนลงล่าง
💡 กฎที่ชอบออกสอบ
1. border-radius: 50% บนกล่องสี่เหลี่ยมจัตุรัส (width = height) จะได้วงกลมสมบูรณ์
2. box-shadow ค่าลบ = เงาเลื่อนไปทางซ้าย/บน, ค่าบวก = ขวา/ล่าง ส่วนค่าที่ 3 (blur) ยิ่งเยอะเงายิ่งฟุ้ง
3. อิโมจิถือเป็น "ตัวอักษร" ธรรมดา ปรับสีไม่ได้ด้วย color แต่ปรับขนาดได้ด้วย font-size และจัดกลางได้ด้วย text-align หรือ flex
05

โครงสร้างหน้าเว็บ + การทำเมนูนำทาง

ทุกไฟล์ Workshop ที่ทำมาจะมีโครงร่างหน้าตาคล้ายกัน: header → nav → hero → main content → footer ส่วนนี้คือ "เค้าโครง" ที่ใช้ซ้ำได้ทุกหน้า จำโครงนี้ไว้แล้วเปลี่ยนแค่เนื้อหาข้างในตามแต่ละหน้า

  • <header> ส่วนหัวของหน้า มักมีโลโก้/ชื่อเว็บ + เมนู
  • <nav> ครอบกลุ่มลิงก์เมนู อยู่ข้างในหรือข้างนอก header ก็ได้
  • <main> เนื้อหาหลักของหน้า ควรมีแค่ 1 อันต่อหน้า
  • <section> แบ่งเนื้อหาเป็นหมวดๆ ภายใน main
  • <article> เนื้อหาที่จบในตัวเอง เช่น การ์ด 1 ใบ, โพสต์ 1 อัน
  • <footer> ส่วนท้ายหน้า มักมีลิขสิทธิ์/ลิงก์เสริม
โค้ดตัวอย่าง — โครงหน้าเว็บมาตรฐาน (ใช้ได้ทุก workshop)
<body> <!-- ส่วนหัว: โลโก้ + เมนู --> <header> <div class="brand"> <h2>เรียนรู้เว็บเบื้องต้น</h2> </div> <nav> <a href="index.html">Home</a> <a href="heading.html">Heading</a> <a href="formatting.html">Formatting</a> </nav> </header> <!-- เนื้อหาหลักของหน้า --> <main> <section> <h1>หัวข้อหลักของหน้านี้</h1> <p>เนื้อหา...</p> </section> </main> <!-- ส่วนท้ายหน้า --> <footer> <p>&copy; 2026 เว็บของฉัน</p> </footer> </body>

🔗 การเชื่อมเมนูไปหน้าอื่น (multi-page)

เว็บที่ทำใน Workshop มีหลายไฟล์ (index.html, W03-heading.html, w04-01-formatting.html ฯลฯ) เมนูแต่ละหน้าต้องมี href ชี้ไปชื่อไฟล์จริงให้ตรงกัน ถ้าพิมพ์ชื่อไฟล์ผิดหรือตัวพิมพ์เล็ก/ใหญ่ไม่ตรง ลิงก์จะพัง

⚓ Anchor Link — เชื่อมภายในหน้าเดียวกัน

ใช้ตอนอยากทำเมนู "สารบัญ" กดแล้วเลื่อนไปหัวข้อในหน้าเดียวกันเลย โดยไม่เปลี่ยนไฟล์ (เห็นในหน้า index.html ที่มีลิงก์ TOP กลับขึ้นบน)

โค้ดตัวอย่าง — anchor link กดแล้วเลื่อนไปหาหัวข้อ
<!-- ปุ่มลิงก์ ต้องมี # นำหน้าชื่อ id --> <a href="#heading">ไปหัวข้อ Heading</a> <a href="#top">กลับขึ้นบนสุด</a> <!-- ปลายทาง ต้องมี id ตรงกับที่ลิงก์ไป (ไม่มี #) --> <h1 id="top">HTML Tutorial</h1> <h2 id="heading">Heading</h2>
⚓
เคล็ดลับ: ถ้าอยากให้เลื่อนแบบนุ่มๆ ไม่กระตุก ให้เติม html { scroll-behavior: smooth; } ใน CSS — เห็นได้ในไฟล์ index.html จริงของ workshop
💡 กฎที่ชอบออกสอบ
1. ลิงก์ไปหน้าอื่น = href="ชื่อไฟล์.html" ส่วนลิงก์ในหน้าเดียวกัน = href="#id" (มี # นำหน้า)
2. ปลายทางของ anchor link ต้องใส่ id="..." ไว้ที่แท็กเป้าหมาย (ไม่มี #)
3. <nav> ไม่ได้จำกัดว่าต้องมีแค่ลิงก์ในเมนูบนสุด จะใช้ทำสารบัญข้างในหน้าก็ได้
4. ชื่อไฟล์ในไทยกับอังกฤษ ตัวพิมพ์เล็ก/ใหญ่ต่างกัน ถือเป็นคนละไฟล์ (เช่น Index.html ≠ index.html บนบางระบบ)

การเชื่อม CSS เข้ากับ HTML

มี 3 วิธีเชื่อม CSS เข้ากับ HTML แต่ละแบบมีข้อดี/ข้อเสียต่างกัน ในไฟล์ Workshop ที่ทำมาใช้ทั้ง internal (เขียนใน <style> ในไฟล์เดียวกัน) และ external (แยกไฟล์ .css ต่างหาก)

Inline CSSในแท็ก
ใส่ style ตรงในแท็กนั้นๆ เลย ใช้เฉพาะจุดเล็กๆ
style="color:red;"
Internal CSSในไฟล์เดียวกัน
เขียนรวมไว้ใน <style> ที่ <head> ของไฟล์นั้น
<style>...</style>
External CSSแยกไฟล์
เขียนใน .css คนละไฟล์ แล้วลิงก์เข้ามา ใช้ซ้ำได้หลายหน้า
<link href="style.css">
1) Inline CSS — เขียนใน attribute style ตรงๆ
<p style="color: red; font-size: 20px;">ข้อความสีแดง</p>
2) Internal CSS — เขียนใน <style> ในไฟล์เดียวกัน (แบบ W03-heading.html)
<head> <style> body { font-family: Arial, sans-serif; background-color: #f3cded; } h1 { color: rgb(43, 43, 122); } </style> </head>
3) External CSS — แยกไฟล์ .css แล้วลิงก์เข้ามา (แบบ w04-01-formatting.html)
<!-- ไฟล์ w04-01-formatting.html --> <head> <link rel="stylesheet" href="css/formatting.css"> </head> /* ไฟล์ css/formatting.css แยกต่างหาก */ body { font-family: 'Kanit', Arial, sans-serif; background-color: #F6F1FF; }

Internal — เหมาะกับ...

หน้าเว็บเดี่ยวๆ ไม่กี่หน้า อยากให้ทุกอย่างอยู่ในไฟล์เดียว เปิดไฟล์เดียวจบ เหมาะตอนส่งงาน/ทำ workshop สั้นๆ

External — เหมาะกับ...

เว็บที่มีหลายหน้า อยากให้ทุกหน้าหน้าตาเหมือนกัน แก้ที่ไฟล์ .css ทีเดียว ทุกหน้าที่ลิงก์ไฟล์นี้เปลี่ยนตามหมด

💡 กฎที่ชอบออกสอบ
1. <link> ต้องอยู่ใน <head> เท่านั้น และเป็น self-closing tag
2. path ของไฟล์ .css ต้องตรงกับตำแหน่งไฟล์จริง เช่น href="css/formatting.css" แปลว่ามีโฟลเดอร์ชื่อ css เก็บไฟล์นั้นอยู่
3. ลำดับความสำคัญเวลาเจอ CSS ชนกัน: inline > internal/external (inline ชนะเสมอ ไม่ว่าจะเขียน CSS ไว้ที่ไหนก็ตาม)
4. ถ้าลิงก์ external CSS ผิด path หน้าเว็บจะยังเปิดได้ปกติ แต่ไม่มีสไตล์ใดๆ เลย (เหมือนหน้าเปล่าๆ)

List — แท็ก <ul> <ol> <li>

แท็กทำรายการ มี 2 แบบหลัก คือรายการไม่มีลำดับ (ใช้จุด/สัญลักษณ์) กับรายการมีลำดับ (ใช้เลข/ตัวอักษร) ทุกรายการต้องใช้ <li> ครอบแต่ละข้อเสมอ ไม่ว่าจะเป็น ul หรือ ol

  • <ul> Unordered List — รายการไม่มีลำดับ ใช้จุด/สัญลักษณ์นำหน้า
  • <ol> Ordered List — รายการมีลำดับ ใช้เลข/ตัวอักษรนำหน้า
  • <li> List Item — แต่ละข้อของรายการ ต้องอยู่ใน ul หรือ ol เท่านั้น

<ul> — Unordered List

ใช้เมื่อลำดับก่อนหลังไม่สำคัญ เช่น รายการวัตถุดิบ, เมนูนำทาง, รายการคุณสมบัติ

<ol> — Ordered List

ใช้เมื่อลำดับสำคัญ เช่น ขั้นตอนการทำอาหาร, อันดับที่ 1-2-3, คำแนะนำที่ต้องทำตามลำดับ

โค้ดตัวอย่าง — Unordered List
<ul> <li>Coffee</li> <li>Tea</li> <li>Milk</li> </ul>
โค้ดตัวอย่าง — Ordered List
<ol> <li>Coffee</li> <li>Tea</li> <li>Milk</li> </ol>

🎨 list-style-type — เปลี่ยนหน้าตาสัญลักษณ์

ปรับรูปแบบจุดนำหน้าของ <ul> ได้ด้วย CSS property นี้

  • ข้อ 1
  • ข้อ 2
disc
จุดกลมทึบ (ค่าเริ่มต้น)
  • ข้อ 1
  • ข้อ 2
circle
วงกลมโปร่ง
  • ข้อ 1
  • ข้อ 2
square
สี่เหลี่ยมทึบ
  • ข้อ 1
  • ข้อ 2
none
ไม่มีสัญลักษณ์เลย (ใช้ทำเมนู nav บ่อยสุด)

🔢 ol type / start — เปลี่ยนรูปแบบเลขและจุดเริ่ม

แท็ก <ol> ปรับรูปแบบตัวเลข/ตัวอักษรได้ด้วย attribute type และเลือกเลขเริ่มต้นได้ด้วย start

  1. หนึ่ง
  2. สอง
type="1"
ตัวเลข 1, 2, 3 (ค่าเริ่มต้น)
  1. หนึ่ง
  2. สอง
type="A"
ตัวอักษรใหญ่ A, B, C
  1. หนึ่ง
  2. สอง
type="a"
ตัวอักษรเล็ก a, b, c
  1. หนึ่ง
  2. สอง
type="I"
เลขโรมัน I, II, III
โค้ดตัวอย่าง — เริ่มนับจากเลขอื่นด้วย start
<ol type="A" start="3"> <li>จะเริ่มที่ C</li> <li>ตามด้วย D</li> </ol> <!-- หรือใช้ CSS property list-style-type แทน type attribute ก็ได้ --> ol { list-style-type: upper-roman; } /* I, II, III */ ol { list-style-type: lower-alpha; } /* a, b, c */ ol { list-style-type: decimal; } /* 1, 2, 3 */
💡 กฎที่ชอบออกสอบ
1. <li> ห้ามอยู่โดดๆ ต้องอยู่ใน <ul> หรือ <ol> เท่านั้น
2. อยากได้เมนูนำทางแบบไม่มีจุด มักใช้ <ul> + list-style-type: none; ร่วมกับ display: flex; (แบบเมนู nav ที่ทำมาในทุก workshop)
3. type เป็น attribute ใส่ในแท็ก HTML ส่วน list-style-type เป็น CSS property — ใช้อย่างใดอย่างหนึ่งพอ ถ้าใส่ทั้งคู่ CSS จะเป็นตัวชนะ
4. start="3" ใช้ได้กับ <ol> เท่านั้น ไม่มีใน <ul> (เพราะ ul ไม่มีลำดับ)

เช็กความจำก่อนสอบ

🧠 ลองปิดโพยแล้วตอบคำถามนี้ดู

  1. H1 ควรมีกี่อันต่อหน้า และทำไม?
  2. <strong> ต่างจาก <b> ยังไง ทั้งที่หน้าตาเหมือนกัน?
  3. <em> ต่างจาก <i> ยังไง?
  4. ถ้าอยากให้ข้อความมีเส้นขีดฆ่ากลาง ใช้แท็กอะไร?
  5. สูตรเคมี H₂O ต้องใช้แท็กตัวห้อยชื่ออะไร?
  6. ลิงก์ที่กดแล้วเปิดแท็บใหม่ ต้องเติม attribute อะไรในแท็ก <a>?
  7. แท็ก <img> attribute ตัวไหนที่ "ห้ามลืม" ใส่เด็ดขาด?
  8. อยากทำให้รูปภาพกลายเป็นลิงก์ ต้องเอาแท็กไหนครอบแท็กไหน?
  9. อยากทำกล่องให้เป็นวงกลมสมบูรณ์ ต้องตั้ง border-radius เท่าไหร่ และ width/height ต้องเป็นยังไง?
  10. ถ้าอยากได้กรอบเส้นประ (ไม่ใช่เส้นทึบ) ต้องเปลี่ยนคำว่าอะไรใน property border?
  11. เมนูที่กดแล้วเลื่อนไปหัวข้อในหน้าเดียวกัน ต่างจากเมนูที่กดแล้วไปอีกหน้ายังไง (href ต่างกันตรงไหน)?
  12. ถ้า CSS แบบ inline กับ internal เขียนสีให้แท็กเดียวกันไม่ตรงกัน อันไหนจะชนะ?
  13. อยากลิงก์ไฟล์ CSS แยกเข้ามาในหน้า HTML ต้องใช้แท็กอะไร วางไว้ตรงไหนของไฟล์?
  14. <ul> กับ <ol> ต่างกันตรงไหน ควรเลือกใช้แบบไหนตอนไหน?
  15. อยากทำเมนู nav แบบไม่มีจุดนำหน้า ต้องใช้ CSS property อะไร?
  16. <ol type="A" start="3"> จะเริ่มแสดงตัวอักษรอะไรเป็นข้อแรก?
